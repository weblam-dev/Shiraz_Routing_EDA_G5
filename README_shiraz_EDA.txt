 پروژه مسیریابی در شبکه خیابان‌های شیراز

 معرفی پروژه

هدف این پروژه، مدل‌سازی شبکه خیابان‌های شهر شیراز و آماده‌سازی محیطی برای اجرای الگوریتم‌های مسیریابی است. در این پروژه از داده‌های شبکه معابر و نمایش دوبعدی شبکه برای بررسی ساختار خیابان‌ها و آماده‌سازی محیط مسیریابی استفاده می‌شود.

 ساختار پروژه

text
project_submission/
├── shiraz_drive.graphml
├── design_results/
│   ├── shiraz_2d_grid.npy
│   └── shiraz_2d_grid.png
├── eda_results/
│   ├── missing_nodes.csv
│   ├── missing_edges.csv
│   ├── edges_statistics.csv
│   ├── nodes_statistics.csv
│   ├── node_degrees.png
│   ├── road_types.png
│   └── street_lengths.png
└── docs/
    ├── design_report.md
    └── eda_report.md


فایل `shiraz_routing_EDA.ipynb` نیز برای تحلیل اکتشافی داده‌ها و انجام آزمون‌های اولیه محیط در نظر گرفته شده است.

 وظایف پروژه

- بارگذاری داده‌های شبکه خیابان‌های شیراز
- نمایش شبکه خیابان‌ها به‌صورت گراف
- تبدیل شبکه خیابان‌ها به یک گرید دوبعدی
- بررسی مقادیر گمشده و تکراری
- شناسایی نوع ویژگی‌ها و محاسبه آمار توصیفی
- رسم نمودارهای تحلیلی مربوط به طول خیابان‌ها، اتصال گره‌ها و انواع راه‌ها
- بررسی اولیه صحت ساخت محیط مسیریابی

 معرفی داده‌ها

داده‌های پروژه شامل اطلاعات گره‌ها، یال‌ها، مختصات جغرافیایی و ویژگی‌های خیابان‌ها هستند.

بر اساس گزارش اولیه پروژه، شبکه دارای مشخصات زیر است:

- تعداد گره‌ها: ۴۲٬۲۷۵
- تعداد یال‌ها: ۹۱٬۳۹۴
- میانگین طول یال‌ها: حدود ۷۲٫۷۴ متر
- میانه طول یال‌ها: حدود ۵۰٫۱۰ متر

این مقادیر باید با اجرای کد و بررسی داده‌های واقعی مجدداً تأیید شوند.

 پیش‌نیازهای اجرا

برای اجرای کدهای پروژه به موارد زیر نیاز است:

- Python 3
- کتابخانه NumPy
- کتابخانه Pandas
- کتابخانه Matplotlib
- کتابخانه NetworkX
- محیط Jupyter Notebook یا Visual Studio Code

برای نصب کتابخانه‌های موردنیاز، دستور زیر را اجرا کنید:

bash
pip install numpy pandas matplotlib networkx


 نحوه اجرای پروژه

۱. مخزن پروژه را از گیت‌هاب دریافت یا دانلود کنید.

۲. مطمئن شوید پوشه `project_submission` و فایل‌های داده در دسترس هستند.

۳. فایل `shiraz_routing_EDA.ipynb` را در محیط Jupyter Notebook یا Visual Studio Code باز کنید.

۴. سلول‌های نوت‌بوک را به‌ترتیب اجرا کنید.

۵. نتایج تحلیل داده‌ها، نمودارها و آزمون‌های اولیه محیط را بررسی کنید.

در صورتی که مسیر پوشه پروژه متفاوت باشد، باید متغیر `PROJECT_DIR` در نوت‌بوک اصلاح شود.

 نکته مهم درباره گرید دوبعدی

طبق مستندات طراحی پروژه، مقدار `1` نشان‌دهنده سلول خیابان و مقدار `0` نشان‌دهنده سایر سلول‌ها است. با این حال، در برخی پیاده‌سازی‌های الگوریتم‌های مسیریابی، مقدار `1` برای موانع و مقدار `0` برای مسیر آزاد استفاده می‌شود.

بنابراین، پیش از اجرای الگوریتم‌هایی مانند BFS، DFS یا A، باید قرارداد مقادیر گرید مشخص و در تمام بخش‌های کد یکسان‌سازی شود.

 محدودیت‌های فعلی

تحلیل اولیه بر ساختار گراف، کیفیت داده‌ها، آمار توصیفی و بررسی گرید تمرکز دارد. برای تأیید عملکرد کامل محیط، باید آزمایش‌های بیشتری برای پیدا کردن مسیر معتبر انجام شود.

همچنین لازم است مشخص شود محدودیت‌هایی مانند یک‌طرفه بودن خیابان‌ها، جهت حرکت و ممنوعیت ورود چگونه در مدل مسیریابی اعمال می‌شوند.

 منبع داده‌ها

داده‌های شبکه معابر پروژه از OpenStreetMap تهیه شده‌اند. شرایط استفاده و ارجاع به منبع داده باید مطابق الزامات پروژه و مجوز مربوط به داده‌ها درج شود.
